# Restful Booker API Testing

## Project Overview
This project focuses on manual API testing of the Restful Booker API using Postman. The objective was to verify API functionality, validate responses, check authentication, and identify potential issues through positive and negative test scenarios.

## Tools & Technologies
- Postman
- Microsoft Excel
- Microsoft Word
- GitHub
- REST API
- JSON

## Testing Scope
The following API operations were tested:

- GET – Retrieve booking details
- POST – Create a new booking
- PUT – Update an existing booking
- PATCH – Partially update booking details
- DELETE – Delete a booking
- Authentication – Generate and validate authentication tokens

## Testing Activities
- Executed positive and negative test scenarios.
- Verified HTTP status codes and response bodies.
- Validated JSON response structure and data types.
- Tested authentication and authorization.
- Tested booking creation, retrieval, updates, and deletion.
- Documented defects and potential validation issues.
- Prepared test cases, bug report, and test summary report.
